# 🎮 Simon Says Game

An interactive **Simon Says memory game** built using **HTML, CSS, and JavaScript**.

The game generates a sequence of colors that the player needs to remember and repeat in the correct order. As the level increases, the sequence becomes longer and the game becomes more challenging.

---

## 🚀 Features

- 🎯 Random color sequence generation
- 🧠 Memory-based gameplay
- 📈 Increasing difficulty with levels
- 🖱️ User input validation
- 🎨 Interactive button animations
- ⚡ JavaScript DOM manipulation
- 🔄 Game-over and restart functionality
- 📱 Simple and responsive interface

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling and animations
- **JavaScript** – Game logic and user interaction
- **DOM Manipulation** – Dynamic interaction with game elements
- **Event Handling** – Handling keyboard and button events

---

## 🎮 How to Play

1. Press any key to start the game.
2. Watch the color that flashes.
3. Remember the sequence.
4. Click the buttons in the same order.
5. Each correct round increases the level.
6. If you select the wrong color, the game ends.
7. Try to reach the highest level possible!
